# Paquete de correcciones Camel / POM / OpenRewrite

Este paquete contiene las correcciones necesarias para el caso observado en `member-phygital` y módulos similares.

Incluye:
- consistencia de versiones Camel;
- deduplicación y saneamiento del POM;
- orden de recipes OpenRewrite;
- registry de compatibilidad de componentes;
- validación de artefactos;
- detección OSGi/bundle;
- parser de errores de compilación;
- autofix por rondas;
- gates previos al compile;
- reporte correcto de causa raíz.
